# 運動資料說明（sportsdata）

本資料夾包含運動清單 `exercises.json`。注意：JSON 不支援註解，請不要在 `exercises.json` 檔內加入註解或多餘欄位，以免影響程式載入與隨機挑選邏輯。

## 難易度統計（以目前 `exercises.json` 為準）
- 簡單（難易度 1）：9 個
- 中級（難易度 2）：7 個
- 困難（難易度 3）：4 個

> 如需更新統計，請先更新 `exercises.json`，再同步修改此摘要，或提供需求讓我們加上一鍵統計腳本。

## 欄位格式
每筆運動物件需包含以下欄位：
- `ID`：數字，唯一識別碼
- `名稱`：字串
- `簡介`：字串
- `運動時間`：數字（秒）
- `難易度`：數字（1=簡單、2=中級、3=困難）
- `是否做過`：布林

## 其他說明
- 若需要機器可讀的統計，可新增 `exercises_meta.json`（例如 `{ "counts": { "1": 9, "2": 7, "3": 4 } }`）。請避免改變 `exercises.json` 的結構（目前是陣列），以免影響既有程式。

- 最終分數分配運動
   
- 低   8 ~ 18    2個低難度運動+1中
- 中   18 ~ 30   1個低難度運動+2中+1難
- 中高 30 ~ 40 3中+2難
- 高   40 ~ 50 2中+3難
